# Wrkone QA Automation Framework

## Overview
This repository contains the Selenium BDD Automation Framework developed for the Wrkone application.

## Tech Stack
- Java 17
- Selenium WebDriver
- Cucumber BDD
- TestNG
- Maven
- Git & GitHub

## Project Structure

```
src
 ├── main
 │    └── java
 └── test
      ├── java
      └── Resources
           └── Features
```

## Features Automated
- Login
- Add User
- User Management

## Run the Tests

```bash
mvn clean test
```
